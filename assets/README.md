# Assets

Coloque neste diretório sua foto com um destes nomes:

- `foto-perfil.webp` (recomendado);
- `foto-perfil.png`;
- `foto-perfil.jpg`;
- `foto-perfil.jpeg`.

O portfólio detectará automaticamente o formato disponível.

Para o currículo, adicione:

- `curriculo.pdf`.

Até que os arquivos sejam adicionados, o portfólio exibirá um avatar com as iniciais VN e informará que o currículo ainda não está disponível.
